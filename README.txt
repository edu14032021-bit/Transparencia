PAINEL DE ACESSOS - GITHUB PAGES

Como publicar:
1. Envie todos os arquivos deste ZIP para o repositório no GitHub.
2. Ative o GitHub Pages em Settings > Pages.
3. Escolha a branch main e a pasta /root.
4. Acesse o link gerado pelo GitHub Pages.
5. No Chrome Android, abra o site e use o botão "Instalar app" quando aparecer.

Arquivos principais:
- index.html: página principal do painel.
- manifest.json: configuração PWA.
- service-worker.js: cache e suporte básico offline.
- offline.html: tela quando estiver sem conexão.
- icons/: ícones do app.

Observação:
Alguns sites externos podem bloquear abertura dentro do iframe por política de segurança do próprio site.
