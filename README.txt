PAINEL DE ACESSOS - PWA COM DIAGNÓSTICO

Arquivos na raiz do GitHub Pages:
- index.html
- manifest.json
- manifest.webmanifest
- service-worker.js
- offline.html
- diagnostico.html
- .nojekyll
- icons/

IMPORTANTE:
1. Envie os arquivos extraídos, não o ZIP fechado.
2. O index.html precisa ficar na raiz do repositório.
3. Acesse pelo link do GitHub Pages, por exemplo:
   https://SEUUSUARIO.github.io/NOME-DO-REPOSITORIO/
4. Não teste pelo arquivo local e não teste pela página de código do GitHub.
5. Depois de publicar, abra /diagnostico.html para verificar HTTPS, Manifest e Service Worker.

Se o Chrome Android não mostrar instalar:
- Abra pelo Chrome Android.
- Aguarde 30 segundos.
- Recarregue a página.
- Abra o menu ⋮ e procure Instalar app ou Adicionar à tela inicial.
- Acesse diagnostico.html e tire print do resultado.
